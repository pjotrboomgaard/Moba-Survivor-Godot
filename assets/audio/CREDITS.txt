no attribution required.

Picked for a punchier, more "mouth sound"-style feel (vocal exclamations, pops, splats, laser
zaps) with multiple takes per event where it's heard often, so hits/clicks/deaths don't all
sound identical. See autoload/audio_service.gd for which take(s) back which in-game sound id.

Arena background music (assets/audio/music/arena_theme.ogg) started from Mixkit's "Bold and
Brash" (https://mixkit.co/free-stock-music/, Mixkit License, same terms as above), run through
a lowpass + bitcrush + vinyl-noise pass so the pixel-art chiptune reads as lo-fi rather than a
bright straight chiptune loop.
